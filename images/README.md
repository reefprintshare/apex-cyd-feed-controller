# Project Images

This folder contains public screenshots and photos for the DIY Apex CYD Feed Controller & Status Display.

The current images document the finalized v0.2.0 interface, including the normal idle screen, active Apex countdown, command confirmation, Fusion feed state, staged skimmer restoration, and alert/footer examples.

## Current Image Files

| File | What it shows |
|---|---|
| `main-screen.png` | Normal idle screen with the finalized black background, raised orange header, Wi-Fi bars, Apex-data and Home Assistant freshness indicators, colored button rims, and `SELECT FEED ACTION` footer panel |
| `apex-feed-countdown.png` | Active Apex Feed D countdown with active-button styling |
| `apex-cancel-confirmation.png` | Apex Cancel confirmation shown in the footer |
| `fusion-feed-active.png` | Active Fusion 15 feed with the dynamic `FUSION CANCEL` button |
| `fusion-restore-countdown.png` | Staged Fusion restore state showing the skimmer-restoration countdown |
| `trident-testing-info-footer.png` | Green informational footer example |
| `wavemaker-info-footer.png` | Blue operational-status footer example |
| `temperature-warning-footer.png` | Amber warning footer example |
| `temperature-alarm-footer.png` | Red alarm footer example |
| `alert-rotation-example.png` | Rotation between multiple non-priority informational or operational statuses |
| `feature-walkthrough-collage.png` | Combined visual walkthrough of major controller states |

## Before Uploading an Image

Review every image for:

- Browser address bars
- Apex IP addresses or hostnames
- Home Assistant URLs
- Wi-Fi names
- Entity IDs
- Account names
- Email addresses
- Device serial numbers
- QR codes
- Camera views
- Private notifications
- Background details that identify your home

Crop, blur, or replace anything private before uploading.
