# Project Images

This folder is for public screenshots and photos of the DIY Apex CYD Feed Controller & Status Display.

Recommended image types:

- Main touchscreen screen
- Fusion feed active screen
- Apex feed active screen
- Alarm footer example
- Warning footer example
- Informational footer example
- CYD mounted near the aquarium
- 3D-printed enclosure or stand
- Wiring/power photo, if external hardware is later added

## Suggested Filenames

```text
main-screen.png
fusion-feed-active.png
apex-feed-active.png
alarm-footer.png
warning-footer.png
info-footer.png
mounted-controller.jpg
enclosure.jpg
```

## Before Uploading an Image

Review every image for:

- Browser address bars
- Apex IP addresses or hostnames
- Home Assistant URLs
- Wi-Fi names
- Entity IDs
- Account names
- Email addresses
- Device serial numbers
- QR codes
- Camera views
- Private notifications
- Background details that identify your home

Crop, blur, or replace anything private before uploading.

## README Image Use

Once a clean main screenshot is added, it can be shown near the top of the root README with:

```markdown
![DIY Apex CYD Feed Controller](images/main-screen.png)
```

Keep image filenames simple and descriptive so they are easy to reference in documentation and forum posts.
